# SAIFE

제조 사업장 위험성평가 AI Agent.
작업 전 안전점검표, 위험성평가표, 산업재해조사표를 설비 단위로 연결해 기록함.

제4회 경남 AI/SW 경진대회 출품작 (일반부 개인, 사회문제 해결형 AI Agent).

---

## 실행

```bash
git clone https://github.com/sodanhyun/saife.git
cd saife
cp .env.example .env          # GEMINI_API_KEY 입력 시 실제 모델 사용, 비워 두면 오프라인 모드
docker compose up -d --build
# http://localhost:5173
```

| 키 | 동작 |
|---|---|
| 있음 | Gemini 응답, 사진 분석, 임베딩 검색 |
| 없음 (오프라인 모드) | 모델 문장만 고정 스크립트로 대체. 도구 호출, 데이터 조회, 등급 판정, 근거 검색(키워드)은 실제 실행. 사이드바에 "오프라인 모드" 표시 |

- 컨테이너 3개(postgres, backend, frontend). 빈 볼륨 기준 헬시까지 약 32초(2026-09-29 실측)
- 근거 청크 41,281건은 헬시 이후 백그라운드 적재(약 1분)
- `GET /api/system/status`로 모드와 적재 건수 확인

### 개발 환경

```bash
docker compose -f docker-compose.dev.yml up -d   # DB
cd backend && ./gradlew bootRun                  # :8080
cd frontend && npm install && npm run dev        # :5173
```

스키마는 Flyway(V1~V19, `backend/src/main/resources/db/migration`). `ddl-auto: validate`.

## 화면

| 경로 | 메뉴 | 기능 |
|---|---|---|
| `/` | 현장 사진 분석 (첫 화면) | 사진 한 장으로 사진 상황, 안전 문제(위치 상자), 문제별 예방 방법. 사진 속 설비 제안과 설비에 기록(순회점검 기록, 같은 위험요인 병합), 반영/제외, 개선대책 |
| `/equipment` | 설비 현황 | 요약 지표, 오늘 할 일(기한 경과 조치, 승인 대기, 작업 보류, 조사표 기한, 순회점검 주기), 설비 카드 |
| `/equipment/:id` | 설비 이력 | 현재 등급과 판정 근거, 평가, 개선대책, 작업 전 점검, 사고 이력 |
| `/work-plan` | 작업 전 점검 | 작업 내용 입력, 판정에 필요한 항목만 질문, 위험성 판정, 유사 재해사례(원문의 개요, 원인, 대책), 관리감독자 승인(잠정조치), 서식 출력(작업자 안내, 서명란), 점검 기록 검색 |
| `/incident` | 사고 보고 | 사고 시점 기준 사전 기록 조회, 수시평가 생성, 조사표 기한, 같은 설비 작업 보류(수시평가 확정 전 새 점검표 승인 불가) |
| `/action` | 개선대책 | 미이행, 기한 경과, 완료 목록과 검색. 이행 확인: 증빙 사진과 사진 대조(대책이 사진에 보이는지 항목별), 이행 내용, 확인자, 개선 후 위험성(상이면 불가) |
| `/assessment/:id` | 수시평가 | 참여 근로자, 허용 가능 여부, 개선대책, 확정 시 작업 보류 해제 |
| `/form/*` | 서식 | 위험성평가표, 작업 전 안전점검표, 작업계획서(제38조), 산업재해조사표, 재발방지 검토서 |

서식은 백엔드 렌더(Thymeleaf). 인쇄 또는 PDF 저장.

### 판정과 확정

| 단계 | 처리 |
|---|---|
| 위험요인 후보, 문안 | AI(Gemini) |
| 위험성 등급 | 룰 엔진(`RiskRuleEngine`), 판정 근거 문자열과 조문 표기 |
| 증빙 사진 대조 | AI(Gemini), 항목별 확인/안 보임/판단 불가 |
| 반영/제외, 승인, 이행 확인(개선 후 위험성), 확정, 제출 | 관리감독자, 안전관리자 |

### 근거 자료

| 종류 | 출처 |
|---|---|
| 조문 | 법제처 국가법령정보 (산업안전보건법, 시행규칙, 산업안전보건기준에 관한 규칙) |
| KOSHA GUIDE | 한국산업안전보건공단 |
| 재해사례 | 공단 사고사망 속보, 국내재해사례. 점검표에는 원인과 대책 절이 있는 국내재해사례 원문을 잘라 표시(`CaseDigest`, 모델 미사용) |
| MSDS | 공단 MSDS (물질별 조회, 캐시) |

검색: 벡터와 키워드 RRF 결합, parent 청크 확장, Flash 리랭크(4점 미만 제외), 오프라인 모드는 키워드 검색.
본문 인용 번호는 해당 턴에 표시된 근거 카드 번호만 허용(후처리 검증).
사진과 PDF는 백엔드 캐시 프록시(`/api/media/**`)로 제공.

## 제약

- 인증 없음. 단일 사업장, 내부망 기준. 공개 네트워크 배포 대상 아님
- 사진 분석은 사진에 보이는 안전조치 누락만 대상. 기계 동력 상태, 인터록, 환기 적정성 제외
- 데모 사업장, 인물, 기록은 시연용 데이터
