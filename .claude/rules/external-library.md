# 외부 라이브러리 작업 규칙

## 리서치 후 코드 수정 원칙

외부 라이브러리(Recharts, MUI 등)의 prop이나 동작이 기대와 다르거나 확신이 없을 때, **추측으로 시행착오하지 않는다.**

코드를 수정하기 전에 반드시 아래 중 하나 이상을 수행한다:

1. `node_modules/` 소스코드 직접 확인 — 해당 prop이 내부적으로 어떻게 처리되는지 추적
2. 공식 문서 확인
3. Agent를 통한 외부 자료 리서치

## 금지 패턴

- prop 이름만 보고 동작을 추측하여 반복 수정
- 한 번 실패한 접근을 미세 변형만 바꿔 재시도
- "안 되면 다른 값으로" 식의 무작위 시도

## 필수 패턴

- 첫 시도가 실패하면 즉시 소스코드/문서 확인으로 전환
- 라이브러리 내부 동작 원리를 파악한 뒤 정확한 해결법 적용
